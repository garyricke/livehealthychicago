Viviana — the Outlook question

I looked, and the short answer is that this isn’t something the HTML can fix. Outlook’s compose window runs on Word’s engine and can’t host a designed email no matter how it’s written — only received mail renders properly. That’s exactly why your workaround works, and it’s the standard way designers deal with Outlook, not a hack:

  • Use it for Friday: send from Gmail to your Rush inbox, then forward from Outlook. The forwarded copy keeps the design.
  • If you’re on classic Outlook for Windows, there’s one more route: Insert → Attach File → pick the saved .html file → use the dropdown on Insert and choose Insert as Text. It renders the file as the message body. (Doesn’t exist in new Outlook or Mac.)
  • The real fix is the newsletter sender we talked about — paste in addresses, it sends this design from a proper service, with a working unsubscribe. I’m building that for a couple of clients anyway; target is well before January so you don’t need Mailchimp.
