Newsletter Sender

Add people, pick an issue, test it, then send. Every email has its own unsubscribe link.

Setup

1Who gets it

Paste addresses in any format: one per line, separated by commas, or copied from an email. Anyone who unsubscribed stays unsubscribed, even if you add them again.

2The issue

Pick an issue, have Claude design a new one from your notes or a document, or paste email HTML. The preview is exactly what people will get.

Design a new issue with Claude

Describe what it should cover, attach a Word document, or link a Google Doc (or all three). Claude designs it in the newsletter’s style. You can ask for changes afterward, and nothing goes out until you test and send.

Google Docs need sharing set to “Anyone with the link”. Images in a Word file aren’t carried over; paste image links into the instructions instead.

Ask for changes

    3Send a test

    Required before sending to the list. Any change to the subject or the issue needs a new test.

    4Send to the list

    Each person gets it once. If a send stops partway, run it again and it picks up where it left off.
